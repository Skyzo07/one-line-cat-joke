# The One-Line Cat Joke That Lands

One joke about cats, one line, written to `/output/entry.txt` by `main.ts`
(Node 22, deterministic — no network, no clock, no randomness).

The joke:

> My cat went to therapy and came back with a list of my faults, laminated.

It was picked from 20 original candidates scored against the judge's five
criteria in order, then checked by a CrowLLM judge panel; the full candidate
table and panel results live in the workspace (`candidates.md`,
`panel-results.json`), not in this entry.
